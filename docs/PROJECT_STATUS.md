## 🎯 Ключевые особенности

### Умная пагинация (v2.0)

```typescript
// 1. Собирает ВСЕ вакансии из БД
// 2. Кэширует в Redis (если указан userId)
// 3. Отдает нужную страницу
// 4. Возвращает totalPages

GET /api/vacancies?keywords=developer&userId=telegram_123&page=1&limit=10

{
  "data": [...], // 10 вакансий
  "meta": {
    "total": 150,
    "totalPages": 15,  // ← Бот знает когда остановиться!
    "currentPage": 1,
    "limit": 10
  }
}
```

### Умный поиск

```typescript
// VacancyManager автоматически:
// 1. Проверяет БД
// 2. Если данных нет → парсит СЕЙЧАС
// 3. Если данные старые → обновляет в ФОНЕ
// 4. Отдает результат моментально

const result = await vacancyManager.search({
  keywords: ['nodejs'],
  locations: ['chisinau'],
  page: 1,
  limit: 10
});
```

### Семантический поиск

```typescript
// Находит похожие профессии в словарях
GET /api/vacancies?keywords=программист&useSemanticSearch=true

// Найдет: Developer, Software Engineer, Программист, IT специалист, и т.д.
```
